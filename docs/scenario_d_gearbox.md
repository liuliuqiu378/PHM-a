# 场景 D：齿轮箱健康评估（振动信号仿真 + 故障诊断）

> 对应代码：`src/scenarios/scenario_gearbox/sim.py`。
> 数据：本教程用**物理仿真**生成，机理透明、可对照课本。

![齿轮啮合与故障示意](figures/illustrations/gear_schematic.png)

## 物理机理（对得上课本）
- 齿轮啮合频率 `GMF = 齿数 Z × 轴转频 f_shaft`（每对齿啮合一次产生一次冲击）。
- **健康齿轮**：振动是 GMF 各次谐波 + 高斯噪声，波形平稳。
- **故障齿轮**（断齿/剥落）：每转一圈故障齿多一次强冲击，相当于对 GMF 做 `f_shaft` 的幅值调制 → 在 GMF 两侧出现 `f_shaft` 间隔的**边带**，且时域**峭度(kurtosis)**显著升高。

## 仿真做法
用「衰减振荡核」与每转一次的冲击序列做卷积，模拟冲击经齿轮/轴承传递后的局部铃振（注意：最初用绝对时间衰减导致冲击只在 t=0 附近存在，是 bug，已修正）。

## 实测结果（60 健康 / 60 故障）
- 随机森林分类准确率 **100%**。
- 特征重要性：边带占比 **0.552** > RMS **0.361** > 峭度 **0.087**。

说明：本仿真的故障冲击信噪比高，所以分得很干净；真实现场噪声大、边带弱，需要更细致的特征（小波、阶次跟踪）和更多数据。这里重点是**把机理和诊断链路讲通**。
