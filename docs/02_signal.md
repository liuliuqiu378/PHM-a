# 第 2 层：数据层 —— 信号处理与特征

> 目标：把"看不懂的振动波形"变成"能看出病"的频谱和特征。

## 2.1 肉眼为什么看不出故障

看一段 CWRU 信号：

```bash
python src/module_02_signal/demo_fft_envelope.py
```

![CWRU 频谱与包络解调](figures/signal/cwru_spectrum_envelope.png)

> 先看一张**原理示意图**（概念，非真实数据）：冲击如何把载波调幅、在频谱上长出边带、再经包络谱露出故障频率。

![包络解调原理示意](figures/illustrations/envelope_concept.png)

时域上，Normal 和 InnerRace 看起来都是"噪声"。因为轴承点蚀的冲击能量，**被机器结构的宽频振动盖住了**。直接看时域/原始 FFT 几乎分不出来——这就是必须做信号处理的理由。

## 2.2 频域：FFT 能看到"共振"，但看不到"故障频率"

原始 FFT 频谱里能看到整机共振峰，但轴承故障特征频率（约 100~200 Hz）相对很弱。
解决思路：**包络解调**。

## 2.3 包络解调（Envelope Demodulation）—— PHM 的"照妖镜"

点蚀每次滚珠压过缺陷，产生一个脉冲；脉冲被结构共振放大成一串"短促咣当"。
步骤：

1. 带通滤波到共振频带（如 2~5 kHz），把"咣当"单独捞出来；
2. 希尔伯特变换取包络（把高频载波剥掉，留下调制包络）；
3. 对包络做 FFT —— 故障特征频率（BPFI/BPO/BSF/FTF）会清清楚楚冒出来。

图中红色（InnerRace）的包络谱在 **BPFI≈162 Hz** 处出现尖峰，蓝色（Normal）没有。
这一步就是第 3 层"诊断"的物理依据。

## 2.4 时频分析：故障是"怎么随时间变严重"的

- **STFT / 小波**：看频率成分随时间变化，适合非平稳信号；
- 退化过程中，故障特征频率的幅值会**随运行时间增长**——这正是第 4 层 RUL 的基础。

## 2.5 特征工程：给机器学习喂"好饲料"

| 类型 | 典型特征 | 含义 |
|------|----------|------|
| 时域 | RMS、峰值、峭度(Kurtosis)、峰值因子 | 峭度对冲击敏感，早期故障峭度升高 |
| 频域 | 频谱峰值频率、特定频带能量 | 直接对应故障特征频率 |
| 时频 | 小波能量熵、包络谱幅值 | 兼顾时间与频率信息 |

`src/common/signal_utils.py` 已封装：`time_features()`、`fft_spectrum()`、`envelope_spectrum()`、`fault_frequencies_6205()`，诊断章会直接复用。

跑 `demo_fft_envelope.py` 后，把带通频带从 (2000,5000) 改成 (3000,6000)，观察 BPFI 尖峰是否更明显？为什么？（提示：不同结构共振频带不同，选对带通是包络解调的关键。）
