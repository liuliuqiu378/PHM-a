# 第 3 层：算法层 —— 故障诊断

> 目标：把第 2 层的特征，喂给模型，自动判断"现在是哪一种故障"。

## 3.1 诊断在做什么

故障诊断是 **分类问题**：给定一段振动信号，输出它属于 {Normal, Ball, InnerRace, OuterRace} 的哪一个（也可扩展到更多类/更细的位置）。

> 先建立画面：下面是滚动轴承剖面与缺陷位置示意（红★=缺陷点），不同缺陷位置对应不同故障特征频率（BPFI/BPFO/BSF/FTF）。

![轴承剖面与缺陷位置](figures/illustrations/bearing_geometry.png)

两条技术路线：

| 路线 | 代表方法 | 优点 | 缺点 |
|------|----------|------|------|
| 传统 ML | SVM / RF / KNN + 人工特征 | 可解释、数据少也好用 | 特征要人设计，上限受限于特征 |
| 深度学习 | 1D-CNN / Autoencoder | 自动学特征、上限高 | 需要数据量、可解释性弱 |

> 深度学习路线（1D-CNN）的结构示意：直接在原始波形上自动学特征，末端接 4 类分类头。

![1D-CNN 结构示意](figures/illustrations/cnn_arch.png)

本教程两条都做，并对比效果。

## 3.3 特征为什么有效（可解释性）

`src/common/signal_utils.feature_vector()` 产出 14 维特征：

- 时域 5 维：RMS/峰值/峭度/峰值因子/峰峰值 —— 峭度和 RMS 对冲击敏感；
- 频带能量占比 5 维：故障能量集中在特定频带；
- 包络谱在 4 个故障特征频率(BPFI/BPFO/BSF/FTF)处的幅值 —— 第 2 层物理知识的直接编码。

**工程启示**：做 PHM，先想清楚"物理上什么会变"，再设计特征，往往比无脑上大模型更稳。

## 3.4 深度学习：1D-CNN 端到端

1D-CNN 可以 **不吃人工特征**，直接吃原始波形，自己学滤波器。结构：

```text
输入波形(2048,)
  └─ Conv1d(1->16, k=15) + ReLU + MaxPool
  └─ Conv1d(16->32, k=15) + ReLU + MaxPool
  └─ Conv1d(32->64, k=15) + ReLU + MaxPool
  └─ AdaptiveAvgPool + Dropout + FC -> 4 类
```

运行（需要 torch，建议 GPU）：

```bash
python src/module_03_diagnosis/train_1dcnn.py
```

本机真实结果（RTX 4090 D，cu121）：

| 协议 | 1D-CNN 准确率 |
|------|---------------|
| 窗口级(同工况) | 0.9256 |
| 文件级(跨工况) | **0.7296** |

![1D-CNN 混淆矩阵](figures/diagnosis/cnn_confusion_matrix.png)

## 3.5 把两种路线、两种协议放一起看（重点）

| 协议 | RF(物理特征) | 1D-CNN(原始波形) |
|------|--------------|------------------|
| 窗口级(同工况) | **97.7%** | 92.6% |
| 文件级(跨工况) | 67.3% | **73.0%** |

这张表是本教程最重要的一个"反直觉"结论：

1. **同工况下，物理特征 + 随机森林吊打小 CNN**（97.7% vs 92.6%）。原因：轴承故障频率是明确的物理量，人工编码进特征后，模型几乎不需要学就能区分；而原始波形里故障是微弱的调制，小 CNN 没训够/结构不够好。
2. **跨工况时，原始 CNN 反而比手工特征泛化更好**（73.0% > 67.3%）。说明手工特征"过拟合"到了训练时的特定负载，而 CNN 从原始信号里学到了更负载无关的东西。
3. **两者在换负载后都大幅掉点**（RF 97.7%→67.3%，CNN 92.6%→73.0%）。这就是工业现场的真实痛点：**模型在实验室很准，到另一台机器/另一种工况就拉胯**。

这三点直接引出第 4 层之后要讲的：域适应（Domain Adaptation）、迁移学习、以及"用物理特征做冷启动 + 用深度学习做精细化"的工程组合拳。

## 3.6 这一步你学到了什么

- 诊断 = 分类；特征工程仍非常重要，别迷信深度学习；
- 传统 ML 在数据有限、要可解释、同工况时首选；
- 评测协议决定结论：一定要做"跨文件/跨工况"验证，否则会高估；
- 1D-CNN 能自动学特征，是 PHM 深度学习入门的最佳练手。
