## 1. 同步平均 (TSA, Time Synchronous Averaging)：把"别的机器"的噪声平均掉

**问题**：现场一台齿轮箱旁边还站着好几台别的设备，录音里全是别人的声音。你想看这台齿轮箱"每转一次"的故障冲击，却被背景噪声埋了。

**直觉**：故障是"**跟着这台轴转**"的——每转发生一次，相位固定。而别的机器的噪声"不跟这台轴同步"，相位随机。

**做法**：用键相/转速脉冲把信号切成一段段"每转一段"，然后**逐点对这么多段求平均**。
- 同步的故障：每次都在同一位置 → 越平均越清楚；
- 不同步的噪声：每次位置乱跳 → 平均后趋近 0。

![TSA 同步平均](figures/signal/advanced2_tsa.png)

> 一句话：**TSA = 用"转"当节拍器，把不踩节拍的杂音全消掉**。特别适合齿轮断齿、轴裂纹这类"每转一次"的故障。它和 [`12`](./12_signal_advanced.md) 的阶次跟踪是"同一类思想"——都用转速做参考系，只不过一个在时域平均、一个在角域重采样。

## 2. 倒频谱 (Cepstrum)：把"一堆等间距边带"压成一个峰

**问题**：齿轮的频谱里常有**一串等间距的边带**（像梳子）。间距很重要（它对应转频或某故障频率），但"数梳子齿"又慢又容易数错。

**直觉**：频谱里的"等间距重复结构"，在倒频谱里会**塌成一个尖峰**。倒频谱的横轴叫"倒频率 (quefrency，单位秒)"，它和频率互为倒数——边带间距 40Hz，倒频峰就落在 `1/40 = 25 ms`。

![倒频谱](figures/signal/advanced2_cepstrum.png)

> 一句话：**倒频谱是"频谱的频谱"**，专治"重复结构/回声"。真实用途：
> - 齿轮**多阶边带**、螺旋锥齿轮、轴对称故障 → 一秒读出边带间距；
> - 还能查"拍频/回声"（像山洞里说话的回响），在机械里对应"结构多级共振链"。

## 3. 转子动力学：谱上的"指纹"——不平衡 / 不对中 / 松动 / 油膜涡动

旋转机械（电机、泵、风机、汽轮机）的故障，**看谱线位置就能大致判断**，这是现场工程师的基本功。

![转子动力学谱](figures/signal/advanced2_rotor.png)

| 谱线特征 | 对应故障 | 生活类比 |
|---|---|---|
| **1× 转频** 独大 | 不平衡 | 洗衣机甩干时衣服堆一边，嗡——按转频晃 |
| **2× 转频** 明显 | 不对中（联轴器/轴弯曲） | 两轮没对齐，每转两次"磕碰" |
| **0.5× 转频**（半频） | 松动 / 碰磨 | 轴轻微蹭到壳，转两圈才蹭一次 |
| **0.42× 转频**（亚同步） | **油膜涡动 / 油膜振荡** | 见下 |

**临界转速 (Critical Speed)**：转子是个"旋转的弹簧"，有自身固有频率。当转频**扫过固有频率**时共振，振幅暴增——所以升速/降速要"快冲过"临界区，不能在临界转速附近久留。

**油膜涡动 / 油膜振荡**（转子动力学最"玄"的一块）：滑动轴承里的油膜本来托着轴，但油会"带着轴打转"，产生一个约 **0.42× 转频** 的自激振动。它**不随转速升高成比例增大，而是被固有频率锁死**——一旦激发，越修越难压，是汽轮机/压缩机的大敌。注意它和"不平衡 1×"完全不同：**亚同步（<1×）几乎一定是自激/油膜类问题**，这是判断的关键。

> 一句话：**转子看"几倍转频"：1×不平衡、2×不对中、0.5×松碰、0.42×油膜**；再结合临界转速，就知道该"动平衡"还是"换轴承"还是"调对中"。

## 4. 疲劳与 RUL 的物理根：Paris 定律 / Miner 累积损伤

[`04_预测`](./04_prognostics.md) 用"指数退化曲线"拟合 RUL，但材料到底怎么坏的？接上真实物理，RUL 才有"根"、才不会乱外推。

**S-N 曲线（应力-寿命）**：材料承受的应力越小，能扛的循环次数越多；双对数坐标下近似直线。**低于疲劳极限，理论上永不坏**——这就是"无限寿命设计"的依据。

**Paris 定律（裂纹怎么长）**：已有微小裂纹时，每加载一次裂纹长大一点。裂纹扩展速率：
```
da/dN = C · (ΔK)^m
```
- `a` = 裂纹长度，`N` = 循环次数；
- `ΔK` = 应力强度因子幅值（和载荷、裂纹长度都有关）；
- 关键直觉：**裂纹越长 → ΔK 越大 → 长得越快** → 退化是**加速**的（呼应 [`04`](./04_prognostics.md) 指数/双指数趋势）。这解释了为什么"早期慢慢爬、后期突然垮"。

**Miner 累积损伤 (Palmgren-Miner)**：不同工况轮流加载，损伤是可**线性累加**的：
```
Σ (n_i / N_i) = 1  → 预计失效
```
`n_i` 是在第 i 种载荷下实际循环数，`N_i` 是该载荷下能扛的总数。累加满 1 就坏。

> 一句话：**Paris 解释"为什么退化越到后头越快"，Miner 解释"变工况下寿命怎么折算"**。把这两个接进 [`04`](./04_prognostics.md) 的数据驱动 RUL，就是"physics-informed 预测"——模型外推不再是无依据的曲线延长。

## 5. 循环平稳 (Cyclostationarity)：比包络更"认"调制的提取法

[`02`](./02_signal.md)/[`12`](./12_signal_advanced.md) 用包络解调抓轴承冲击。但**噪声特别大、或多故障混在一起**时，包络也会吃力。

**直觉**：轴承/齿轮的故障信号有个特点——它的统计特性（均值、相关）**按转频周期性地变化**（因为每转来一次冲击）。这种"周期平稳"信号，用**循环自相关 / 谱相关密度 (SCD)** 能把故障频率和调制分开，对噪声更鲁棒，且能同时显示"载波 + 循环频率"二维图。

> 一句话：**循环平稳 = 不只看"有没有峰"，还看"峰是不是按转频有节奏地来"**，因此在强噪声、多故障下比普通包络更稳。工业高端软件里有，但计算重、解释也重，一般作为包络的"加强版"备用。

## 6. HHT / EMD：给"非平稳、非线性"信号办张身份证

前面 FFT/STFT 都假设信号"频率成分基本稳"。可真实退化信号常是**频率随时间漂移、非线性**的（比如转速缓变 + 故障萌生）。

**EMD（经验模态分解）**：不事先假设基函数，而是**让数据自己分解**成若干 IMF（本征模态函数）——每个 IMF 是"一个局部频率成分"。像把一段嘈杂的音乐**自动拆成鼓、贝斯、人声各一层**。

**Hilbert 变换（HHT = EMD + Hilbert）**：对每个 IMF 做 Hilbert，得到"瞬时频率-时间"曲线，即**时频图**，能看到频率怎么随时间走。

> 一句话：**EMD 把信号"自己拆层"，Hilbert 给每层标上随时间变的频率**——适合早期微弱、频率漂移的故障。缺点是"模态混叠"（拆层不稳）、物理可解释性弱，所以多作探索/辅助，不像 FFT 那样是"标准动作"。
