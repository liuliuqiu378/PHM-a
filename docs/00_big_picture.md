# 第 0 层：PHM 全景

> 目标：用一张图讲清楚 PHM 是什么、为什么需要、整条技术链怎么走。

## 0.1 一句话理解 PHM

**PHM（Prognostics and Health Management，故障预测与健康管理）**，就是给机器装上一套"健康监测 + 提前预警"的系统：

- 通过传感器持续采集振动、温度、电流等信号；
- 用信号处理与机器学习算法判断"现在有没有病"（**诊断**）；
- 进一步预测"还能撑多久"（**预测 / RUL**）；
- 最终给出"什么时候修、怎么修"的维护决策。

它的对立面是传统的 **事后维修（坏了再修）** 和 **定期维修（到点就修）**，前者风险高，后者浪费大。PHM 追求的是 **按需维修（Condition-Based Maintenance）**，在可靠性与成本之间取得最优。

## 0.4 为什么这件事值得做

- 工业现场：风电、轨交、航空发动机、电机产线都迫切需要降低非计划停机；
- 数据红利：传感器越来越便宜，数据越攒越多，算法落地门槛在下降；
- 岗位需求：设备智能、预测性维护是工业 AI 的核心方向之一。

## 0.5 一个最小的直觉例子

假设一台电机轴承开始有裂纹，振动信号里会出现一个特定频率的能量突增。PHM 系统要做的是：
1. **听到**（传感器采到振动）；
2. **听懂**（FFT 看到那个频率的峰）；
3. **判断**（这是内圈故障还是外圈故障）；
4. **预测**（按能量增长趋势推算还能跑多久）；
5. **行动**（在下一次计划停机前安排更换）。

后面的章节，就把这 5 步一步步拆开讲透、写可跑的代码。
