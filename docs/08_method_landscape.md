# 方法总图谱：PHM 用什么方法、区别在哪、何时选哪种

> 目标：把教程里散落在各模块的算法，收成一张"谱系图"。面试或被问"你们用啥方法、为啥用这个"时，能一句话讲清全局，再下钻到具体模块。
> 本文不重复公式，只做**分类 + 对比 + 选型**。每个方法都标了"本教程在哪跑通、实测效果"。

## 0. 先建立坐标系：PHM 方法的两条主轴

```
                  数据驱动 ──────────────────────────────► 纯数据
                    ▲                                      ▲
  物理/机理驱动      │   信号处理/特征   传统ML   深度学习   无监督/主动学习
  (model-based)     │
                    │
  纯物理模型 ────────┴──────────────────────────────────► 纯机理
```

- **横轴**：从"靠物理方程/机理"到"靠数据自己学"。越靠右越不需要懂物理，但越需要数据和可解释性越差。
- **纵轴**：输入信息量——监督（有标签）vs 无监督（只有正常/无标签）。
- 真实系统常是**混合**（物理约束 + 数据驱动），见 §6。

## 1. 方法谱系总表

| # | 类别 | 代表方法（教程中） | 输入 | 数据需求 | 优点 | 缺点 | 本教程实测 / 出处 |
|---|------|-------------------|------|----------|------|------|-------------------|
| ① | 物理模型法 | 退化指数拟合 `HI=exp(-kt)` | 历史 HI 序列 | 极少（可零训练） | 可解释、零数据也能外推 | 早期极不稳定、假设强 | RUL RMSE≈**96.6**（`04`） |
| ② | 信号处理 / 特征驱动 | FFT、包络解调、阶次跟踪、峭度 | 原始波形 | 无标签 | 物理可解释、"照妖镜" | 靠人调频带、只适用已知机理 | BPFI≈162Hz 尖峰（`02`） |
| ③ | 传统监督 ML | SVM / RF / KNN + 人工特征 | 特征向量 | 中（百~千样本/类） | 可解释、小数据好用 | 特征靠人设计、上限受特征限 | RF 窗口级 **0.977** / 文件级 **0.673**（`03`） |
| ④ | 监督深度学习 | 1D-CNN / Autoencoder(有监督头) | 原始波形/特征 | 大（千~万样本） | 自动学特征、上限高 | 需数据量、可解释弱、易过拟合 | CWRU 4 类分类（`03`/`A`） |
| ⑤ | 无监督异常检测 | Autoencoder 重构误差 | 仅正常样本 | 只需正常数据 | 解决"故障样本难获取" | 只报异常**不分类型**、阈值难定 | CWRU AUC=1.0（理想，`07`） |
| ⑥ | 序列/RUL 数据驱动 | LSTM / Transformer 回归 | HI 时间序列 | 中~大退化曲线 | 抓时序依赖、比模型法稳 | 需退化数据（稀缺） | LSTM RMSE≈**29.7** vs 模型法 96.6（`04`） |
| ⑦ | 漂移 + 主动学习 | 不确定度采样 + 滑动窗口重训 | 流数据 + 专家标签 | 标签稀缺 | 同样标签误差减半、抗概念漂移 | 需专家愿打标（延迟/成本） | 主动 **0.025** / 随机 0.050 / 不重训 0.250（`07`） |
| ⑧ | 部署/压缩 | ONNX 导出、INT8 静态量化 | 训练好模型 | — | 跨平台、省体积/内存 | 小模型量化不一定更快 | 31KB/3.3×、精度无损（`05`） |

## 2. 最容易混淆的三组"区别"

**A. ② 信号处理 vs ③ 传统 ML vs ④ 深度学习**
- 信号处理：人定规则（"包络谱里 BPFI 处有峰 = 内圈故障"）——**可解释但只能抓已知机理**。
- 传统 ML：人提特征（RMS/峭度/频带能量…）+ 模型学边界——**机理仍靠人，但分类更鲁棒**。
- 深度学习：模型自己从波形提特征——**上限高、但成黑箱、需大量数据**。
- 一句话：从"人懂物理"到"机器自己懂"，代价是数据量和可解释性。

**B. ④ 有监督 DL vs ⑤ 无监督 AE**
- 监督：训练集里有 Ball/InnerRace 等**明确标签** → 能分类型，但故障样本极难凑齐（见 `07` "异常样本难题"）。
- 无监督：只喂正常样本，重构误差超阈即判异常 → **绕开标签荒**，但"异常"是笼统的、不知道是哪类故障、对维修直接价值低。
- 现实打法：**无监督先圈可疑 → 主动学习优先标这些**（呼应 `07` 漂移闭环）。

**C. ① 模型法 vs ⑥ 数据驱动 RUL**
- 模型法：假设退化是指数/线性 → 零数据可外推，但**设备还很健康时噪声主导、RUL 严重高估**（RMSE 96.6）。
- 数据驱动：LSTM 学时序规律 → 稳得多（RMSE 29.7），但**要"跑到坏"的退化历史**（真实极稀缺）。
- 工程结论：RUL 早期天然难，任何方法都该给**不确定性区间**而非单点（`04` MC Dropout）。

## 3. 选型决策树（面试可背版）

```
有多少标签 / 数据？
├─ 几乎没有故障标签（最常见现场）
│   └─ 无监督异常检测(⑤) 先圈可疑 → 主动学习(⑦) 攒标签
├─ 有正常 + 少量几类故障标签
│   ├─ 数据少(<千/类)  → 传统 ML(③) 或 信号处理(②)
│   └─ 数据多(万级)    → 监督 DL(④)
└─ 目标是"还能跑多久"(RUL)
    ├─ 有退化曲线      → LSTM/Transformer(⑥)
    └─ 只有零星 HI     → 模型法外推(①) + 必带不确定性

部署约束？
├─ MCU/内存几十 MB → 必须 INT8 量化(⑧)，小模型优先
└─ 边缘工控机       → FP32/INT8 ONNX 皆可
```

## 4. 一个必须讲清的"效果幻觉"

教程里很多数字**漂亮得不正常**，讲的时候要主动拆穿：
- `03` RF **0.977** 是窗口级（同文件泄漏），文件级（跨工况）只有 **0.673**——后者才贴近现场。
- `07` 无监督 AUC=**1.0** 是 CWRU 理想数据（干净、平衡、诱导故障）；现场会低得多，且只报异常不分类型。
- `B` 场景 AUC≈1.0 被我们直接标注"近乎确定性、疑数据泄漏"——**AUC=1.0 先怀疑，不是庆祝**。
- `E` PHM2025 留一法 R²=**0.29~0.67**（仅 4 台），说明真实 RUL 数据少、泛化难。

## 6. 前沿：混合（physics-informed）方法

纯数据法在现场常因数据少/漂移而塌房；纯物理法难建模复杂系统。趋势是**把物理约束编进模型**：
- 损失函数加物理正则（如退化单调约束、已知故障频率先验）；
- 用代理模型（PINN / 降阶模型）补数据；
- 本教程未实现，但 `04` 的"模型法"和 `02` 的"故障频率先验"已埋下混合思路的种子。

## 7. 小结
方法没有"最好"，只有"在当前数据/约束下最合适"。**面试加分点不是堆方法，而是能说清"为什么选这个、它的边界在哪、现场会怎样变差"**——本图谱 + 各模块的真实指标，正好支撑这套讲法。
