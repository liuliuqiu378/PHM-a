# 场景 C：锂电池 SOH / RUL 健康预测（等效电路模型仿真）

> 对应代码：`src/scenarios/scenario_battery/sim.py`。
> 数据：本教程用**物理仿真**生成（等效电路模型 + 老化模型），开箱即跑、可复现。

## 为什么用仿真
真实电池数据（NASA、牛津）体积大需下载。为了「可复现、机理透明」，这里用 Thevenin 等效电路模型 + 容量/内阻老化模型自己造数据：
- 端电压 `V = OCV(SOC) - I·R0 - V1`（RC 支路描述极化）。
- 老化：容量 `Q` 随累计吞吐线性衰减，内阻 `R0` 随老化上升。**SOH = Q/Q_nominal**，EOL 定义为 SOH 跌到 80%。

![退化曲线与 RUL 示意](figures/illustrations/degradation_rul.png)

## 要解决的工程问题
真实 BMS 只能「量」到电流、端电压、温度，算不出容量真值。于是用**脉冲内阻测试 + 库仑计数**得到带噪声的 `R0_meas` / `Q_meas`，再估 SOH、外推 RUL。

## 实测结果
- SOH 估计（用前 240 循环训练、预测后段）：RMSE=**0.0206**，R²=**0.78**。
- RUL（EOL 循环）：真实≈**196**，模型外推≈**240**，误差 **44 循环**。

## 关键教学点
1. **SOH 与容量观测值近似线性（SOH≈Q_meas/Q_nominal）**，所以用**线性模型**估 SOH 能稳定外推。
2. **树模型（随机森林）不会外推**：若用 `cycle` 或超出训练区间的 `Q_meas` 当输入，它只能给出训练区边界的恒定错误预测（R² 会变负）——这是 PHM 里「用早期数据估全寿命」最常踩的坑。
3. RUL 外推天然不确定：早期数据只能给出区间，不是点估计。
