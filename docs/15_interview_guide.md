# 面试 / 讲解 5 分钟讲法提纲

> 用途：把教程 `00~14` 收成**一段能背的讲述 + 高频追问的标准回答**。照这个讲，既能显出"全流程都懂"，又能用"讲真话"体现工程经验。
> 配合 [`16_术语表`](./16_glossary.md) 查缩写、[`08_方法总图谱`](./08_method_landscape.md) 复习选型、[`14_应用场景`](./14_applications.md) 接行业。

---

## 一、开场白（约 30 秒，定调子）

> "PHM 是给机器装健康监测：用传感器采振动/温度/电流，先做**诊断**（现在有没有病），再做**预测**（还能撑多久 RUL），最后给出**按需维修**决策。它替代事后维修和定期维修，本质是在'可靠性'和'成本'之间取最优——所以**PHM 是机理+数据+工程+组织的系统工程，模型只是一环**。"

（一句话亮出全景 + 一句"系统工程"收口，立刻区别于只会调模型的人。）

---

## 二、主线（约 2~3 分钟，用"一个轴承"串全场）

按时间线讲**一台电机轴承从健康到失效**的全过程，每段点一下对应文档：

1. **感知**（`01_硬件`）：IEPE 加速度计贴轴承座 → 信号链放大/抗混叠 → 采样率要 >2 倍最高频率（奈奎斯特），否则混叠。
2. **信号处理**（`02`+`12`+`13`）：FFT 看频谱；**包络解调**剥掉轰鸣留敲击声抓轴承点蚀；真实设备**变速**→用**阶次跟踪**；带通靠**谱峭度**自动选；内/外圈靠**调制边带**区分。
3. **特征→诊断**（`02`+`03`+`08`）：提时域(峭度/RMS)/频域/时频特征 → 传统 ML(RF) 或 1D-CNN。无标签时用**无监督自编码器**先抓异常。
4. **预测 RUL**（`04`）：退化曲线 → LSTM/粒子滤波给"剩余寿命+置信区间"；物理上 Paris 定律解释"越往后坏得越快"。
5. **部署**（`05`+`07`）：ONNX/INT8 压到边缘；边缘提特征、云训练；断网缓存+告警收敛成工单。
6. **工程坑**（`07`+`11`）：异常≠可行动、告警疲劳、概念漂移要用主动学习。

> 这段讲完，面试官已确认你**从传感器到工单全链路都懂**。

## 三、方法谱系一句收口（约 30 秒，显全局观）

> "方法分八类：物理模型法 / 信号处理 / 传统ML / 监督DL / 无监督AE / 序列RUL / 漂移+主动学习 / 部署压缩。选型看**标签和数据量**：标签多→有监督；标签荒→无监督AE+主动学习；要可解释→信号处理+物理模型；要上限→DL。没有银弹，是被机理和数据逼出来的（[`08`](./08_method_landscape.md) 选型决策树）。"

## 四、高频追问 + 标准回答（"反杀点"）

| 面试官可能问 | 你的标准回答（带讲真话） |
|---|---|
| 你们诊断准确率多少？ | "教学集 CWRU 上 RF 窗口级 **0.977**，但**跨工况文件级掉到 0.673**——真实现场会更难；无监督 AE 在 CWRU 上 AUC=1.0，那是**理想数据**，现场会低且只能报异常不能分类型。"（主动暴露边界，比报漂亮数字更可信） |
| FFT 为什么不够？ | "恒转速才够；**变速**下故障频率被扫宽、糊成宽带 → 用**阶次跟踪**按转角重采样锁成单线。"（[`12`](./12_signal_advanced.md)） |
| 包络解调带通怎么选？ | "不靠人试——用**谱峭度/Kurtogram**自动定位冲击能量最集中的共振带。"（[`12`](./12_signal_advanced.md)） |
| 内圈外圈怎么区分？ | "内圈随转频 **AM** → 边带 BPFI±fr；外圈固定 → BPFI 单线。是**调制物理**决定的，不是模型硬猜。"（[`09`](./09_fault_sensor_map.md)） |
| 没标签怎么办？ | "无监督自编码器学'正常'，重构误差超阈即异常；再用**主动学习**挑最不确定的样本请专家标，同量标签误差减半。"（[`07`](./07_engineering.md)） |
| 模型上线后数据分布变了？ | "**概念漂移**——用预测不确定性做漂移哨兵，触发**增量重训**（滑动窗口忘旧工况）。"（[`07`](./07_engineering.md)） |
| RUL 给一个天数吗？ | "不给精确天数，给**区间+置信度**（MC Dropout/粒子滤波）。退化是非线性的，早期慢慢爬、后期突然垮（Paris 定律）。"（[`04`](./04_prognostics.md)） |
| 这套用在哪？ | "风电/航空发动机/大型旋转设备**已真落地**；复杂小设备/精准RUL/电池热失控长窗口**还在 PoC**。旋转机械看振动、热力看气路、电池看电压内阻。"（[`14`](./14_applications.md)） |
| 为什么 PHM 落地难？ | "五大壁垒：数据(非平衡/罕见故障)、机理、系统集成(OT隔离)、组织(谁拍板修)、长期运维；还有**告警疲劳**——一串异常要收敛成一个可执行工单才有价值。"（[`11`](./11_industry.md)） |
| 电机也能监测？不用额外传感器？ | "用**MCSA**：直接读变频器电流，转子断条会在电流谱留 `1±2s` 边带（s=转差），**非侵入式**王牌。"（[`09`](./09_fault_sensor_map.md)） |

## 五、收尾（约 30 秒，回扣定位）

> "所以我会把 PHM 讲成：**机理定方向（装什么传感器、看什么频率）→ 数据定精度（特征/模型）→ 工程定可用（边缘云/工单/漂移）→ 业务定价值（少停几次、少过修几次，算 OEE/停机成本）**。模型只是其中一环。"

讲完这一句，整体闭环、定位清晰。

## 附：临场三句保命话（被问住时用）

1. "这个我教程里是用**合成/教学数据**验证的，真实现场 X 会不同，我的处理是…"（显边界意识）
2. "这个问题本质是**调制/退化/漂移**里的哪一类，我会先定性再定量…"（显机理思维）
3. "落地价值我不看准确率，看**非计划停机变计划内、过修变按需修**"（显业务思维）
