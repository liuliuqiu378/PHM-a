# PHM 教程：从传感器到部署的工程实战

> 一套**由内到外、由理论到实际**的预测性维护（PHM）教程。
> 不只讲算法，更把**部署、数据闭环、异常检测、概念漂移**这些决定"能不能真正上线"的工程坑，
> 都用**可运行代码**跑给你看。

预测性维护（Prognostics and Health Management）的目标很朴素：**在机器真坏之前，知道它快不行了**。
但真正落地时，难点往往不在算法，而在系统工程与数据闭环。本教程按"分层"组织：

```text
第 0 层  PHM 全景          它到底是什么、技术闭环、产业价值
   │
第 1 层  硬件层            传感器、信号链、ADC、采样定理
   │
第 2 层  数据层            时域/频域、包络解调、特征工程
   │
第 3 层  算法-诊断         ML + DL 故障分类
   │
第 4 层  算法-预测         RUL 剩余寿命预测
   │
第 5 层  系统层            部署、ONNX、INT8 量化
   │
第 6 层  端到端场景        5 个完整项目（含 1 个真实 RUL 挑战赛）
   │
第 7 层  工程实战          数据闭环、异常检测、边缘-云管线、概念漂移
   │
总览与选型              方法总图谱（选型指南）、故障机理→传感器映射
```

## 这本教程和别的有什么不同

- **每个模块都有能跑的脚本**：不是伪代码，是 `python src/xxx/xxx.py` 直接出图。
- **讲真话**：量化会让小模型变慢、无监督异常检测在真实现场 AUC 不会是 1.0、随机切分数据会虚高
  ——这些反直觉但真实的结论，都如实写在文档里。
- **工程闭环是重点**：你关心的"采集、传递、部署在哪、怎么传、训练闭环、异常样本建立"，
  我用三个可运行 demo 覆盖：无监督异常检测（只用正常数据）、边缘-云数据管线
  （只传特征/告警 + 断网缓存）、概念漂移 + 主动学习闭环。
