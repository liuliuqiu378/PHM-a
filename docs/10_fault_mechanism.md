# 故障机理深入：机器到底是怎么坏的（真入门）

> 前面 `09` 讲了"装什么传感器、能抓什么病"。但**真入门是懂机器"为什么这么坏、怎么一步步坏"**——
> 不懂机理，只能当"调包侠"：别人给特征你就用，结果不对也解释不了。懂机理，才能**选对传感器、定对阈值、解释结果、说服现场**。
> 这一层，才是 PHM 真正的壁垒。本文用生活类比讲清"失效物理"，不堆公式。

## 0. 一句话建立画面

```
   根本原因（磨损/疲劳/腐蚀/蠕变/装配不当）
        │  随时间累积
        ▼
   某个物理量开始异常（振动冲击 / 温度升 / 电流边带 / 铁屑多）
        │  被传感器采到
        ▼
   特征频率/指标越变越明显  →  发展期（PHM 的黄金窗口）
        │
        ▼
   急剧恶化 → 失效/停机
```

PHM 的全部努力，就是**在"发展期"尽早抓住那条异常曲线**，赶在急剧恶化前安排维修。

## 1. 失效的"四大根本机理"（先记这四个）

所有机器故障，本质上逃不出这四类物理过程。其他现象（松动、不对中、异响）多是它们被**诱发或表现出来**的方式。

| 机理 | 大白话 | 生活类比 | 常见于 | 早期信号 |
|------|--------|----------|--------|----------|
| **磨损 Wear** | 两个面反复蹭，材料被一点点刮掉 | 鞋底磨平、橡皮越用越小 | 轴承、齿轮、密封、刹车、活塞 | 振动峭度升、油里有金属屑 |
| **疲劳 Fatigue** | 反复受力，先长微观小裂纹，再慢慢裂开 | 别针来回掰，第 N 次"啪"断 | 轴承点蚀、轴裂纹、齿轮断齿、焊接处 | 周期性冲击（每次受力"响"一下） |
| **腐蚀 Corrosion** | 化学/电化学把材料吃掉 | 铁生锈、铜绿 | 管道、壳体、接头、化工设备 | 壁厚减薄（超声）、泄漏、温度异常 |
| **蠕变 Creep** | 高温+长期受力，慢慢被"压变形" | 热塑料衣架挂重物，慢慢下垂 | 涡轮叶片、炉管、高温紧固件 | 形变、位移、温度漂移 |

> 还有一类"非材料"的诱发因素：**松动、不对中、不平衡、共振、润滑失效、气蚀、过载**。
> 它们本身不是材料失效，但会**加速**上面的四大机理——比如不平衡让轴承受力翻倍→疲劳提前。

## 2. 一条轴承是怎么从"好"到"卡死"的（最经典案例）

以 CWRU 那种滚动轴承点蚀为例，完整物理链：

```text
微小剥落（表面缺陷，<1mm）
   │ 滚珠每压过缺陷一次 → 一次冲击
   ▼
冲击激发结构共振 → 时域出现"短促咣当"、频域长出边带
   │ 缺陷随运行扩大（点蚀→剥落→成片凹坑）
   ▼
冲击能量增强、特征频率幅值随运行时间增长
   │
   ▼
碎裂 / 保持架断裂 / 卡死（急剧失效，往往几小时~几天内）
```

**退化的三阶段**（这是 PHM 的底层逻辑）：

| 阶段 | 特征 | 能不能抓到 | PHM 价值 |
|------|------|-----------|----------|
| 潜伏期 | 缺陷极小，冲击弱 | 被背景振动淹没，**几乎抓不到** | 不现实，别硬来 |
| **发展期** | 缺陷在长大，特征幅值稳定增长 | **可检测、且还有维修窗口** | **黄金窗口——PHM 的主战场** |
| 急剧失效期 | 快速恶化 | 能抓但已来不及计划性维修 | 只能紧急停机 |

> 一句话：**PHM 不是要"预测崩溃那一刻"，而是要在发展期早期，给你留出"安排一次计划性停机"的时间。**

## 3. 为什么"故障会有固定频率"——几何直觉（不用背公式）

很多人被 BPFI/BPFO 吓退。其实直觉很简单：

> 轴承每转**一圈**，内圈上某个固定点，会被**每个滚珠**各压过一次。
> 压的次数 ÷ 转数 = 内圈通过频率 BPFI。
> 所以：缺陷"**每秒钟响 BPFI 次**"。

- 外圈缺陷：滚珠每转过缺陷一次响一下 → BPFO；
- 滚动体自身缺陷：它自转时缺陷每露面一次响一下 → BSF；
- 保持架缺陷：保持架转一圈缺陷扫过一次 → FTF。

**包络解调**（`02` 的核心）就是：把机器整体的"轰鸣"（载波）剥掉，只留下这串"敲击声"（包络），再做 FFT——于是 BPFI 尖峰就清清楚楚冒出来。
这就是为什么 `09` 说"轴承点蚀→振动"：因为**点蚀的物理本质就是周期性冲击，而冲击在频谱上有固定位置**。

## 4. 各故障机理一句话 + 类比

- **齿轮断齿/剥落**：啮合刚度在缺陷齿处突然变小→啮合频率被转频"调制"出边带。类比：自行车缺一个齿，每转一圈"咔哒"响一下。
- **转子不平衡**：重心不在旋转轴上→离心力 ∝ 转速² → 激起 **1×转频** 正弦振动。类比：洗衣机甩干时晃得厉害，就是不平衡。
- **不对中**：两根轴没对正→联轴器受额外弯矩→主因 **2×转频**，常带轴向分量。类比：两轮车筐歪着，骑起来两边受力不均。
- **电机转子断条**：断一根导条→气隙磁动势不对称→转矩脉动→定子电流出现边带 `f ± 2sf`（`s` 转差）。类比：电风扇少一片叶子，转起来发抖、电流也不稳。**这招用电流就能查，不用拆机**——MCSA 的妙处。
- **润滑失效**：油膜破裂→金属直接接触→又磨损又发热。信号顺序：**先温度升 → 再振动峭度升 → 最后油里铁屑暴增**。所以温度是最早的哨兵，油液是最终的铁证。
- **松动**：连接刚度下降→非线性→出现 1/2、1/3 分频和撞击声。类比：螺丝松了的椅子，坐上去"咯吱"还带空程。

## 5. 退化不是直线：浴盆曲线

设备全生命周期失效率呈"浴盆"形：

```text
失效率
高 │╲           ╱╲
   │ ╲         ╱  ╲        ← 磨损期（老化，PHM 关注）
   │  ╲       ╱    ╲
低 │   ╲_____╱      ╲____  ← 随机故障期（偶发）
   └──────────────────────► 时间
   早期失效期          磨损期
```

- **早期失效期**：刚投产，先天缺陷集中暴露（靠质检/磨合解决，不是 PHM 重点）；
- **随机故障期**：偶发，难预测；
- **磨损期**：随老化失效率上升——**PHM 的主战场就在这段**，用退化模型把"失效率抬头"提前翻译为"还能跑多久"。

## 6. 为什么 PHM 难：机理、数据、耦合 的三角张力

```text
   机理清楚（如轴承点蚀）
        │  → 信号处理方法好用、可解释
        ▼
   但现场常是：多故障同时发生 + 工况天天变 + 噪声大
        │  → 纯机理算不准
        ▼
   只能靠数据驱动
        │  → 可数据极少（故障样本稀缺、标注贵）
        ▼
   退回到无监督/主动学习（呼应 07）
```

这就是为什么教程里方法这么多、没有"银弹"：**机理清楚用物理+信号，机理模糊用数据，数据少用无监督**。选型不是喜好，是被"手里的机理和数据"逼出来的（`08` 选型决策树的根源就在这）。

## 7. 小结（面试可背版）

- 机器失效四大根本机理：**磨损、疲劳、腐蚀、蠕变**；其余多为诱发因素。
- 退化三阶段：**潜伏→发展→急剧**，PHM 价值全在"发展期"抢出维修窗口。
- 故障有固定频率，是因为**缺陷每次受力就产生一次冲击**，几何决定了频率（不是玄学）。
- 真壁垒 = 懂机理（能选传感器/定阈值/解释），而不是会跑模型。
