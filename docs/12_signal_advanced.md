## 1. 阶次跟踪 (Order Tracking)：变速下 FFT 会"糊"

[`02`](./02_signal.md) 的包络解调是在**恒转速**下讲的（CWRU 固定转速）。但真实设备：启停、加减速、负载波动，**转速时刻在变**。

后果：一个"每转发生 3 次"的故障，它的频率 = `3 × 转频`。转频一变，这个频率就跟着扫动。普通 FFT 按时间采样，会把这条故障线**抹成一条宽带**——根本看不出是几阶。

![阶次跟踪对比](figures/signal/advanced_order.png)

**解法**：不按"时间"等间隔采样，而按"**转角**"等间隔采样（用键相/转速脉冲做重采样）。在角域里，故障是"每转固定次数"的事件 → 变成角域里一条**干净的线**，单位叫**阶次 (order = 次/转)**。

- 故障（随转速走）→ 角域里**锁定成单线**（图下半：3 阶清晰）；
- 固定频率成分（如 2400Hz 电气哼声，与转速无关）→ 反而在角域里被**糊掉**（因为它不随转角同步）。

> 一句话：**变转速设备的故障特征，要用"阶次"而不是"Hz"来表达**。阶次谱 = 把"随转速扫动"变成"随转角对齐"。

## 2. 谱峭度 / Kurtogram：把"选对带通"从靠人试变成自动定位

[`02`](./02_signal.md) 说"选对带通频带是包络解调的关键"，[`10`](./10_fault_mechanism.md) 也点"包络解调=剥掉轰鸣留敲击声"。但**带通到底选哪段**？教程之前只能"试"。

物理：轴承点蚀的冲击，会**激发结构在某个共振频带**的"咣当"。故障信息就藏在那个共振带里，别的地方只有噪声。

**谱峭度 (Spectral Kurtosis, Antoni)**：对每个频率，算它"包络在时间上的峭度"。峭度对**瞬态/冲击**极敏感、对平稳噪声不敏感 → **峭度高的频带 = 冲击能量集中的共振带**。于是自动定位最优带。

![谱峭度定位最优带](figures/signal/advanced_kurtogram.png)

图左上：SK 曲线在 ~3500Hz 处最高 → 自动锁定共振带；图右上对比：在**最优带**做包络解调，故障频率(120Hz)清晰冒出线；在**错带**(400~1000Hz)做，被噪声淹没、啥也没有。

> 价值：这把 [`02`](./02_signal.md) 那句"选对带通很关键"从**经验**升级成**可计算方法**——也是工业软件（如 MATLAB 的 kurtogram）的标准做法。变体还有**快速谱峭度图 (Fast Kurtogram)**，用小波包在多层频带上算 SK。

## 3. 调制与边带：AM/FM 怎么长出边带，内圈 vs 外圈因此不同

[`09/10`](./09_fault_sensor_map.md) 讲"故障特征频率会出现**边带**"，但没讲边带**怎么来的**。本质是**调制**。

### 3.1 幅度调制 AM → 载波两侧长两根边带
信号 = `(1 + m·cos(2π f_mod t)) · cos(2π f_c t)`。包络随调制频率 `f_mod` 起伏 → 频谱在载波 `f_c` 两侧长出 `f_c ± f_mod` 两根边带。

### 3.2 频率调制 FM → 载波两侧长多阶边带
信号 = `cos(2π f_c t + β·sin(2π f_mod t))`。瞬时频率被调制 → 频谱长出 `f_c ± n·f_mod`（n=1,2,3…）一族边带，调制深度 β 越大边带越多。

![AM/FM 边带](figures/signal/advanced_modulation.png)

### 3.3 为什么这能区分"内圈"和"外圈"故障
回到 [`09`](./09_fault_sensor_map.md) 的轴承：
- **外圈缺陷是固定的**（不随轴转）：冲击固定在空间某点、每次滚珠经过就响 → 频谱主要是 **BPFO 一根线**，边带弱。
- **内圈缺陷随轴一起转**：它每转一圈要穿过"载荷区"一次，载荷区冲击 louder、非载荷区 weaker → 相当于故障被**转频 fr 调幅** → 在 BPFI 两侧长出 **BPFI ± fr、BPFI ± 2fr…** 的边带。

> 所以：看边带间距就能判断缺陷在**转还是不转**的零件上——**这是诊断"内圈 vs 外圈"的物理依据**，而不是靠模型硬猜。同理，齿轮啮合频率 `z·f_r` 被转频调制 → 出现 `fm ± k·f_r` 边带（齿轮故障的典型指纹）。

## 4. 三件套怎么串起来（现场标准流程）

```text
变转速信号
   │ ① 阶次跟踪：按转角重采样 → 阶次谱（锁定故障阶次）
   ▼
共振带里提冲击
   │ ② 谱峭度：自动定位最优带通
   ▼
包络解调
   │ ③ 看边带：AM/FM 调制 → 判断缺陷位置(内/外圈)、故障模式
   ▼
故障特征频率 + 边带结构 → 对应 09/10 的机理表 → 给出"什么病、多严重"
```

这三件 + [`02`](./02_signal.md) 的 FFT/包络 + [`09/10`](./09_fault_sensor_map.md) 的机理表，构成了一套**从原始振动到"说出什么病"** 的完整、可解释的信号处理链路——而且每个环节都有物理理由，不是黑箱。

## 5. 讲真话的边界
- 阶次跟踪需要**转速/键相信号**（没有转角的纯振动，得先用转速估计做重采样，精度下降）。
- 谱峭度在**极低 SNR 或强非平稳**时也会失手，常和**小波包/循环平稳**结合。
- 边带"内圈 vs 外圈"的判断是**统计倾向**，多故障耦合、变转速下边带会混——需结合阶次跟踪（`§1`）先稳定。
- 本 demo 是**合成信号**把原理放大给你看；真实现场的噪声、传递路径、多源耦合比这复杂得多，但**物理机制一致**。
