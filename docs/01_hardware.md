# 第 1 层：硬件层 —— 传感器、信号链与采样

> 目标：搞懂"机器的健康状态"是如何变成电脑里一串数字的。这是 PHM 的地基。

## 1.1 我们测的是什么：典型传感器

PHM 最常用的几种传感信号：

| 传感器 | 测什么 | 常见故障线索 |
|--------|--------|--------------|
| 加速度传感器（IEPE/ICP） | 振动（加速度） | 轴承点蚀、齿轮断齿、不平衡 |
| 温度传感器 | 温度 | 润滑不良、过载、摩擦发热 |
| 电流/电压传感器 | 电机电流 | 转子断条、轴承磨损、负载异常 |
| 麦克风 | 声音 | 松动、撞击、异响 |

**本教程以振动为主战场**：轴承、齿轮的故障几乎都会先在振动里"尖叫"。

## 1.2 信号链：从机器到数字

```text
  机器结构振动
      │
  加速度传感器（压电 + IEPE 恒流源供电）
      │ 模拟电压（mV ~ V，含偏置）
  信号调理（放大 / 抗混叠滤波 / 供电）
      │
  ADC（模数转换，采样率 fs + 分辨率 N bit）
      │
  数据采集卡 / 边缘网关
      │
  PC / 云端（算法）
```

几个必须记住的概念：

![PHM 信号链示意](figures/illustrations/signal_chain.png)

- **IEPE/ICP**：工业加速度传感器最常用的供电+信号复用标准（2 线，恒流源供电，信号叠加在直流偏置上）。好处是抗干扰、可长距离传输。
- **灵敏度**：传感器把物理量转成电压的比例，单位如 `100 mV/g`（g = 重力加速度）。
- **量程**：能测的最大加速度，超量程会削顶失真。
- **量化**：ADC 把连续电压变成离散数字，分辨率 N bit → 最小可分辨电压 = 满量程 / 2^N。

## 1.3 采样定理（奈奎斯特）：为什么会被"骗"

> 采样率 `fs` 必须大于信号最高频率的 **2 倍**，否则高频会被"折叠"成低频，产生**混叠（Aliasing）**，后面算法再强也救不回来。

运行演示看效果：

```bash
python src/module_01_hardware/demo_sampling_aliasing.py
```

![采样混叠仿真](figures/hardware/sampling_aliasing.png)

可以看到：同一个 5 Hz 信号，在 20 Hz 采样下还原正常；一旦低于 10 Hz（奈奎斯特），频谱里就会冒出一个**假的低频峰**——这就是混叠。

**工程对策**：在 ADC 前加 **抗混叠低通滤波器**，把高于 fs/2 的频率先滤掉。

## 1.4 采样率怎么选：以滚动轴承为例

轴承故障频率通常在几百 Hz ~ 几 kHz。经验法则：

- 要看到轴承故障特征频率及其边带，采样率一般取 **10 k ~ 50 k Hz**；
- CWRU 数据集就是 12 kHz（驱动端）和 48 kHz；
- 想看齿轮啮合频率（常到十几 kHz），采样率要更高。

## 1.5 一个直觉练习

如果你只关心电机是否"不平衡"（特征频率 = 转频，约 30 Hz），最低采样率应设为多少？
（答案：> 60 Hz，工程上常取 200~500 Hz 留足余量并兼顾抗混叠滤波器过渡带。）

## 1.6 小结与下一步

你已经知道：信号是怎么从机器振动 → 电压 → 数字；采样率选错会出混叠；抗混叠滤波是必须的。
