# 海缆与铺缆船 PHM：被监测资产变了，玩法也变了

> 接 [`14_应用场景`](./14_applications.md)（行业地图）、[`19_工业案例`](./19_industrial_cases.md)（案例集）、[`20_理论扩宽`](./20_theory_broaden.md)（DGA/功能安全）。
> 前面教程的 PHM 主角都是**工厂里的旋转机械/电池/变压器**。但用户问了一个好问题：**海底光缆、铺缆船，有没有 PHM？**
> 答案是**有，而且分两个层面**（海缆本身 / 铺缆船设备），但"被监测的资产"和失效逻辑跟旋转机械差别很大。本篇把行业论文 + 维护知识落到教程框架里。

---

## 0. 结论先行（面试可直接背）

- **海底光缆/海缆**是"埋在海底、长达几千公里、自己带着传感光纤的资产"。它的 PHM 偏 **防护 + 故障定位 + 入侵检测**，** prognostics（剩余寿命）很弱**——因为 ~70% 故障是突发外因（锚/渔网），不是磨损到期。
- **铺缆船**本身是一堆海工装备（动力定位 DP、线性电缆机、推进器、主机），这里才是**经典 PHM（振动/油液/性能 CBM）**，按船级社规范做。
- 一句话：**海缆看"外力入侵+定位"，铺缆船看"机器健康"，两者都是 PHM，但形态不同。**

## 1. 海底光缆/海缆本身（被监测的资产）

### 1.1 故障成因（行业维护核心知识，来自 ICPC 国际海缆保护委员会）

| 成因 | 占比（ICPC 量级） | 对 PHM 的启示 |
|---|---|---|
| **锚泊 + 渔业拖网**（第三方破坏 TPI） | **65–75%** | 监测重点是"外力入侵"，不是退化 |
| 自然现象（滑坡、海流） | <10% | |
| 电缆自身部件失效 | ~5% | 这才是传统磨损/老化 |
| 原因不明 | 10–20% | |
| 鲨鱼啃咬 | **≈0**（2007–2014 零记录） | 常见误解，可当场纠正 |

> 关键认知：通信海缆的故障**绝大多数是突发外因**，不是寿命到期。所以海缆 PHM 的"P"(Prognostics) 很弱——它做的是**实时感知外力 + 秒级故障定位 + 埋深监视**，而不是给你"还剩 3 年"的 RUL。这点和 [`04`](./04_prognostics.md) 的退化-RUL 思路不同，但"健康监控 H"完全一致。

### 1.2 监测手段（把"传感器"换成海缆自带的光纤）

| 技术 | 物理量 | 用途 | 与本教程对应 |
|---|---|---|---|
| **OTDR** | 瑞利后向散射 | 通信光纤**断点定位**（公里级精度） | 类似 1D 反射/TDR，定位用 |
| **DAS（分布式声学传感）** | 沿纤振动/微应变 | 检测锚坠、拖网、船舶移动（第三方入侵） | 等于"把整条海缆变成一根振动传感器"，类比 [`02`](./02_signal.md) 振动但传感介质是光纤 |
| **DTS（分布式温度）** | 沿纤温度 | 热点/过载（电力缆）/ 动态载流 RTTR | 类比热像但连续全线 |
| **DTSS** | 温度+应变 | 机械疲劳、海床位移 | |
| **DoBS** | 埋深 | 暴露段预警（被渔网勾住前） | 状态量，接 CBM |
| **PD 局放监测** | 放电声（电力缆嵌纤） | 绝缘早期退化（风电送出缆） | 类比 [`19`](./19_industrial_cases.md) 案例 5 变压器 DGA，对象是电缆 |

> 最妙的一点：**海缆自己带着通信用光纤，直接拿它当 DAS 传感阵列（OFS-in-OFCN）**，不用额外装传感器——和 [`09`](./09_fault_sensor_map.md) "传感器选法"思想一致："资产最怕哪种失效 → 用什么传感"，这里传感就长在资产身上。

### 1.3 通信海缆 vs 电力海缆：PHM 形态不同（重点）

- **通信海缆**：故障多为外因 → PHM = **入侵检测(DAS) + 故障定位(OTDR) + 埋深(DoBS)**，几乎不做 RUL。修复方式是"截断重接"，不是"预测到寿命再换"。
- **电力海缆（海上风电送出）**：热退化 + 局放 + 疲劳是真退化 → PHM = **温度/局放/应变趋势 → RUL**，和 [`19`](./19_industrial_cases.md) 变压器、[`13`](./13_signal_advanced2.md) 疲劳 Paris/Miner 是同一思路。**这里才有完整的"健康指标 HI → RUL"链条（[`17`](./17_health_indicator.md)）。**

## 2. 铺缆船设备（船上装备的 PHM）

铺缆船是"海上工厂"，设备清单与监测逻辑和教程旋转机械高度重合：

| 设备 | 失效风险 | PHM 做法 | 对应教程 |
|---|---|---|---|
| **动力定位 DP 系统**（Class 2/3 冗余） | 定位丢失→敷设偏差/事故 | 冗余 + 自诊断 + IMCA 审计；**安全关键** | 对应 [`20`](./20_theory_broaden.md) 功能安全 IEC 61508/SIL（海上版是 DP 分级 + 船级社） |
| **线性电缆机 / 张紧器（LCE）** | 张力失控、轮胎/轴承磨损 | 张力反馈 + 振动 + 工况 | [`14`](./14_applications.md) 旋转机械 / [`19`](./19_industrial_cases.md) 案例 |
| **全回转推进器 / 主机** | 轴承、齿轮、轴系 | **振动 + 油液分析 + 性能趋势**（CBM） | [`14`](./14_applications.md)/[`19`](./19_industrial_cases.md) 经典旋转机械 PHM |
| **主柴油机 / 发电机** | 活塞环、缸套、增压器 | 缸压、示功图、滑油光谱 | [`19`](./19_industrial_cases.md) 往复机械 / [`07`](./07_engineering.md) 油液 |

> 这块 PHM 的"行业标准"是**船级社（DNV / ABS / CCS / LR）入级符号 + 状态监测(CBM)规范**，本质是 ISO 10816/13374 的"船舶版"——和 [`11`](./11_industry.md) 讲的"标准即普通话"完全同构。其中 **DNV Class Note 10.2**（机械状态监测/替代检验安排）、**中国船级社《智能机器处所（智能机舱）指南》2025**（基于 ISO 机械状态监测系列 + MIMOSA-CBM 开放系统）是具体抓手。

## 4. 行业论文与规范（已核实，可引用）

1. **Masoudi, Pilgrim, Newson**, "Subsea cable condition monitoring with distributed optical fiber vibration sensor," *J. Lightwave Technol.*, 37:1352–1358, **2019**, DOI `10.1109/JLT.2019.2893038` — 海缆 DAS 监测奠基论文（嵌入光纤测动态应变）。
2. **Tang, Rao 等**, "Seamless integration of DAS and passive optical networks," *Communications Engineering* (Springer), **2026**, DOI `10.1038/s44172-026-00662-z` — 在**现有通信光纤上叠加传感**（OFS-in-OFCN），亚米级定位第三方入侵，是"通信-感知一体化"前沿。
3. **"A review of maritime equipment PHM from a classification society perspective,"** *Ocean Engineering*, **2024** (ScienceDirect `S0029801824009569`) — 从 **DNV/ABS 船级社视角**综述船舶/海工装备 PHM，直接覆盖铺缆船类海工船。
4. **《海上风电用海底电缆运维技术发展现状及趋势》**, *电线电缆*, **2025**, DOI `10.16105/j.dxdl.1672-6901.20250182` — 中文综述，讲风电海缆在线监测/故障定位。
5. **ICPC**（国际海缆保护委员会）故障统计：锚害+渔业占 65–75%（"Shipping and fishing are the cable culprits," Eurowire 2016；ICPC FAQ）。
6. **DNV Class Note No. 10.2**（机械状态监测/替代检验安排）；**中国船级社《智能机器处所（智能机舱）指南》2025**（ISO 机械状态监测 + MIMOSA-CBM）。
7. 厂商实践方案：AP Sensing（DTS/DAS/DTSS/DoBS + SmartVision）、Yokogawa OpreX、Marlinks/Fluves、NEC、Viavi。

## 5. 收口 + 面试话术

被问"PHM 还能用哪"时，海缆/铺缆船是**拉开认知层次**的好例子：
- **"通信海缆故障 70% 是锚和渔网这种突发外因，所以它的 PHM 不是预测剩余寿命，而是用自带光纤做 DAS 感知外力 + OTDR 定位 + 埋深监视——和工厂旋转机械的 RUL 思路完全不同。"**
- **"铺缆船自己则是最经典的船舶 PHM：DP 系统安全关键按船级社冗余分级，电缆机/推进器/主机做振动+油液 CBM。"**

这正好体现 [`11`](./11_industry.md) 那句：**PHM 不是算法，是"资产最怕什么 → 用什么传感 → 按什么标准判"的系统工程**——海缆和铺缆船只是把这套骨架套到了水下与海上。
