# PHM 从入门到落地：算法工程师成长教程

> 一个从「信号长什么样」讲到「产线可部署系统」的 PHM（故障预测与健康管理）实战教程。

## 一、项目定位与目标

**目标**：帮助有一定 Python 基础、但对 PHM 现场一无所知的算法工程师，系统建立 PHM 专业能力，最终能够独立完成 **数据采集 → 信号处理 → 故障诊断 → 剩余寿命预测 → 工程化落地** 的完整闭环。

**项目风格**：

- 通俗易懂但专业、实际，不空谈理论；
- 每个关键概念都配 **可运行的 Python 脚本 + 自动生成的图**；
- 从硬件/传感器原理讲起，逐步到算法、系统、真实场景；
- 所有成果都落在代码与文档里，方便复用、扩展和交给团队。

## 二、面向人群

- 想转行/入门工业智能、PHM 的算法工程师；
- 做设备健康、预测性维护项目但缺少系统梳理的工程师；
- 需要一套可演示、可交付的 PHM 教学/汇报材料的团队。

## 三、学完你能做什么

1. 看懂振动、温度、电流等传感器信号链，能解释采样、量化、混叠、IEPE/ICP；
2. 对轴承、齿轮等典型故障做 FFT、包络解调、时频分析；
3. 用传统 ML（SVM/Random Forest/KNN）和深度学习（1D-CNN、Autoencoder）做故障诊断；
4. 用退化建模 / LSTM / Transformer / 相似度方法做 RUL（剩余寿命）预测；
5. 把模型封装成可服务的模块，理解边缘/云端部署、数据流、告警与维护决策；
6. 包装出 4 个完整落地场景，每个场景都有数据、模型、效果、演示。

## 四、技术栈

- 环境：`conda env: shaojie`，Python 3.10
- 计算：本地 RTX 4090 D 24G（GPU 推理/训练），CPU 也可 fallback
- 库：NumPy、SciPy、Matplotlib、Scikit-learn、Pandas、PyTorch
- 数据：本地 CWRU 轴承数据集 + PHM2023/2024/2025 挑战赛数据

## 五、学习路径（由内到外，由理论到实际）

| 层级 | 主题 | 产出 |
|------|------|------|
| 第 0 层 | PHM 全景：为什么需要、技术闭环、产业价值 | 认知图 / 技术栈图 |
| 第 1 层 | 硬件层：传感器、信号链、ADC、采样定理 | 采样混叠仿真 / 信号链示意图 |
| 第 2 层 | 数据层：时域/频域/时频、包络解调、特征 | CWRU 信号波形+FFT+包络图 |
| 第 3 层 | 算法-诊断：ML + DL 故障分类 | 训练脚本、混淆矩阵、模型对比 |
| 第 4 层 | 算法-预测：RUL、退化曲线、时序模型 | RUL 曲线、置信区间 |
| 第 5 层 | 系统层：边缘/云、部署、服务化 | 一个可运行的 PHM 演示系统 |
| 第 6 层 | 端到端场景：4 个真实落地方案 | 每个场景含数据、模型、效果、演示 |

## 七、快速开始

```bash
# 1. 激活环境（shaojie 已创建）
conda activate shaojie

# 2. 安装依赖（如未安装）
pip install -r requirements.txt

# 3. 运行一个示例（环境装好后）
python src/module_01_hardware/demo_sampling_aliasing.py

# 4. 查看生成的图
ls figures/
```
